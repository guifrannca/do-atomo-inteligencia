# Do Átomo à Inteligência — WORKZ

Landing page de inscrição para a palestra em 28 de outubro de 2026, às 9h, no Auditório Talkz, em Ribeirão Preto.

## Publicação
Este repositório contém `index.html`, pronto para publicação pelo GitHub Pages.

Para publicar: abra **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/(root)`, e clique em **Save**.

## Cadastro
O formulário envia os dados para o Google Apps Script configurado no HTML. Após publicar, faça um envio de teste e confirme que a inscrição apareceu na aba `Inscrições` da planilha. Como o endpoint está público, proteja o acesso à planilha e monitore envios indevidos.
